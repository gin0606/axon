# デスクトップアプリ

デスクトップアプリ（macOS では `Axon.app`）は、登録したリポジトリの記録を閲覧するだけのアプリです。記録の作成・編集・状態の変更はCLIとエージェントで行います。導入は [使い始める](getting-started.md#インストールと対応環境) を参照してください。

## 登録と `axon gui`

登録する単位は管理root（`.axon/` を持つdirectory）です。アプリの「＋ リポジトリを登録」でフォルダを選ぶか、管理rootの中で `axon gui` を実行して登録します。追跡する運用ではworktreeごとに管理rootが異なるため、worktreeごとに別の登録になります。無視する運用ではlinked worktreeもmain worktreeの管理rootを使うため、同じ登録になります。登録の解除は一覧から外すだけで、リポジトリのfileには触れません。

`axon gui` で未登録の管理rootを開くと、アプリはパスを示して登録してよいかを確かめるダイアログを出します。「登録して開く」を選んだときだけ登録し、Returnでは登録しません。表示されたパスが自分の開こうとしたものか確かめてから登録してください。リンクはWebページなどからも送れるため、未登録のフォルダは確かめるまで読みません。

リポジトリを移動・改名すると、元の登録は登録先が見つからないエラーになります。移動先を改めて登録し、元の登録を解除してください。

## アプリのデータの置き場

登録の一覧（`roots.json`）、表示言語の設定（`settings.json`）、次の起動で復元する画面の状態（`session.json`）は、次の場所に置きます。

| OS | 場所 |
| --- | --- |
| macOS | `~/Library/Application Support/Axon` |
| Linux | `$XDG_DATA_HOME/axon`（未設定なら `~/.local/share/axon`） |

普段の登録の一覧に触れずに試すときは、環境変数 `AXON_GUI_DATA_DIR` に絶対パスを指定してデータの置き場を置き換えます。相対パスは拒否します。

以前の版がアプリ専用の保存先に使っていた `projects.json` と `projects/` は読まず、消しません。そこにある記録を閲覧するには、`projects/<ID>` を管理rootとして登録してください。

閲覧専用の範囲とデータfileの扱いは [デスクトップアプリ](../reference/gui.md) にあります。
