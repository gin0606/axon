# デスクトップアプリ

デスクトップアプリ（macOS では `Axon.app`）は、登録した管理 root（`.axon/` を持つ directory）の記録を閲覧するだけで、記録を変更する操作を持たない。保存先の lock を取らず、`.axon/` 配下に書き込まない。閲覧専用にした理由は [設計判断](../design/decisions.md#デスクトップアプリを閲覧専用にした理由)、作り方と動作要件は [デスクトップアプリの開発](../development/gui.md) にある。

## データ file

アプリが書くのは、アプリのデータの保存場所（OS のユーザーデータ領域の下のアプリ用 directory。環境変数 `AXON_GUI_DATA_DIR` に絶対パスを指定すれば置き換わる）にある次の file だけである。

| file | 内容 |
| --- | --- |
| `roots.json` | 登録した管理 root の一覧。`{"format": 1, "roots": ["<絶対パス>", ...]}` の JSON |
| `settings.json` | 表示言語の設定。`{"format":1,"language":"system"}` の形の JSON で、`language` は `system`・`ja`・`en` のいずれか |
| `session.json` | 次の起動で復元する画面の状態。使えなければ初期値で起動する |
| `instance.lock` | 起動中に保持する単一起動の lock |

`roots.json`・`settings.json`・`session.json` は、一時 file への書き込みと rename で丸ごと置き換える。読めない・解釈できない・未知の `format` の `roots.json` は空として扱わず、登録・解除も含めて書き換えない。破損・未知の形式の `settings.json` は、利用者が置き換えを選んだときだけ上書きする。以前の版がアプリ専用の保存先に使っていた `projects.json` と `projects/` は読まず、消さない。

## 登録した保存先の扱い

登録できるのは `.axon/header.json` を持つ directory だけで、symlink・`.`・`..` を解決した絶対パスで登録する。登録の解除は一覧から外すだけで、登録先の file には触れない。登録先の管理 root か header が見つからない場合はそのリポジトリのエラーとして示し、空のリポジトリとして扱わず、作り直しを促さない。再浮上条件のコマンドは実行しない。

本文と Note は Markdown として描画するが、記録を開いただけで外部へ通信したり、ローカルのものを開いたりしない。リンクは scheme が http・https のものだけを、利用者がクリックしたときに既定のブラウザで開く。画像は読み込まず、代替テキストを示す。

## CLI から開く

`axon gui`（[CLI と表示の契約](cli.md#デスクトップアプリで開く)）は、symlink を解決した管理 root の絶対パスを `me.gin0606.axon://open?root=<percent-encode した絶対パス>` のリンクでアプリに渡す。scheme はアプリの bundle identifier と同じ文字列である。

アプリは、リンクのパスが登録の一覧に文字列として一致すればそのリポジトリを開く。未登録なら、ディスクに触れる前にパスを示して登録してよいかを確かめ、「登録して開く」を選んだときだけ、そのパスが今もそれ自身に解決される（symlink を含まない）ことを確かめてから登録する。別の場所に解決されれば登録しない。キャンセルすれば登録も読み込みもしない。確認では Return で登録せず、パスのバックスラッシュ、制御文字、行・段落の区切り、見えない書式文字（ゼロ幅文字や表示順を入れ替える文字）をエスケープして示す。この確認を置く理由は [設計判断](../design/decisions.md#リンクで開く管理-root-を利用者が確かめる理由) にある。
