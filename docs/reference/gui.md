# デスクトップアプリ

デスクトップアプリ（macOS では `Axon.app`）は、既存のリポジトリなどにある Axon の保存先（`.axon/` を持つ管理 root）を登録し、その記録を閲覧するだけで、記録を変更する操作を持たない。記録の作成・編集・Note の追加・状態や構造の変更は CLI とエージェントが行う。アプリが書き込むのは、アプリのデータ領域にある登録の一覧と、次の起動で復元する画面の状態だけである。閲覧専用にした理由は [設計判断](../design/decisions.md#デスクトップアプリを閲覧専用にした理由)、作り方と動作要件は [デスクトップアプリの開発](../development/gui.md) にある。

## 保存場所の規則

アプリのデータの保存場所は OS のユーザーデータ領域（`dirs::data_dir()`）の下のアプリ用ディレクトリで、起動ディレクトリには依存しない。

| OS | 既定の保存場所 |
| --- | --- |
| macOS | `~/Library/Application Support/Axon` |
| Linux | `$XDG_DATA_HOME/axon`（未設定なら `~/.local/share/axon`） |
| Windows | `%APPDATA%\Axon` |

```text
<保存場所>/
    instance.lock   アプリの起動中に保持する単一起動 lock
    roots.json      登録の一覧: 登録した管理 root の絶対パス
    session.json    次の起動で復元する画面の状態
```

- 登録する単位は管理 root（`.axon/` を持つディレクトリ）で、フォルダを選ぶダイアログか `axon gui` のリンク（下の「CLI から開く」）で指定する。選んだパスは symlink・`.`・`..` を解決した絶対パスに正規化し、同じ管理 root は重複して登録しない。同じリポジトリの別の worktree は、管理 root が異なるため別の登録になる。
- 登録できるのは、ディレクトリであり `.axon/` の header（`.axon/header.json`）があるフォルダだけで、満たさなければ理由を示して登録しない。それ以外の保存先の状態（Git の index の unmerged、記録の破損など）は登録の可否に使わず、登録後にそのリポジトリの読み込みエラーとして示す。パスに UTF-8 で表せない文字を含むフォルダは一覧に保存できないため登録しない。
- アプリは登録した管理 root を、探索せずに `axon storage check ROOT` と同じ指定で開く。Git の作業ツリー内では、CLI と同じく index の unmerged を検査する。保存先の lock を取らず、`.axon/` 配下に書き込まない。
- 登録先の管理 root か `.axon/` の header が見つからない場合は、欠けた path を示してそのリポジトリのエラーとし、空のリポジトリとして扱わず、作り直しを促さない。記録ディレクトリ（`.axon/records/`）がない場合は、CLI と同じく記録のない保存先として読む（Git は空のディレクトリを保持しないため、記録を作る前に commit した保存先の checkout にはない）。読めない・開けない場合も同様にエラーとして示す。ほかの登録へはそのまま切り替えられる。
- 登録の解除は一覧から外すだけで、登録先のファイルには触れない。解除したフォルダは再び登録できる。
- `roots.json` は `{"format": 1, "roots": ["<絶対パス>", ...]}` の JSON で、一時 file への書き込みと rename で丸ごと置き換える。file がなければ空の一覧から始める。読めない・解釈できない・未知の `format` の一覧は空として扱わず、登録・解除も含めて書き換えない。登録と解除は、画面が保持する一覧ではなくその時点の file を読み直して変更し、失敗した場合は一覧を読み直して表示する。
- `session.json` は、ウィンドウの大きさと位置（あったディスプレイと、最大化していたか）、最後に選んでいたリポジトリ、状態・種類・label の絞り込み、階層とフラットの切り替えを持つ JSON（`format` は 1）で、`roots.json` と同じく一時 file への書き込みと rename で丸ごと置き換える。label は外した label として持ち、後から増えた label は選ばれた状態で現れる。検索欄の文字、開いていた詳細、「衝突」の選択は持たない。値が変わるたびに書き（ウィンドウの大きさと位置は 0.5 秒動かなかったときと、終了するとき）、異常終了や OS からの終了でも直前の状態が残る。起動しただけでは書かない。失っても困らない情報のため、file がない・読めない・解釈できない・未知の `format` の場合は初期値で起動し、次に値が変わったときに書き直す。ウィンドウの値だけが使えない（大きさが 0 など）場合は、ウィンドウだけを既定にする。書き込みに失敗しても示さない。
- 以前の版がアプリ専用の保存先に使っていた `projects.json` と `projects/` は読まず、消さない。そこにある記録を閲覧するには、`projects/<ID>` を管理 root として登録する。
- 単一起動 lock は OS の file lock（Unix では `flock`）で、起動から終了まで保持する。登録の一覧を変更する操作は lock を保持する起動だけが持ち、一つのアプリの中では一度に一つずつ行う。同じ保存場所で二つ目を起動すると、データを開かずに説明のウィンドウだけを表示する。異常終了すると OS が lock を解放するため、次の起動は妨げられない。

普段の登録の一覧に触れずに試すときは、環境変数 `AXON_GUI_DATA_DIR` に絶対パスを指定してデータの保存場所を置き換える。相対パスは起動場所に依存するため拒否する。

## 操作の仕様

ウィンドウの左列（狭い幅ではパネル。下の「ウィンドウの幅と列」）で、登録したリポジトリを切り替え・登録する。切り替えはメニューから選び、メニューの各項目は表示名とパスを示す。表示名は管理 root のディレクトリ名で、名前の入力・変更は持たない。「＋ リポジトリを登録」でフォルダを選ぶダイアログを開き、選んだフォルダを登録して選択する。ダイアログを閉じたときは登録を変えず、ダイアログを開いていた間は読まなかった選択中のリポジトリを読み直す。登録できない理由と、登録・解除の失敗は中央の列の上部に示す。すでに登録したフォルダを選んだ場合は、その旨を示してそのリポジトリを開く。一覧を読めない・保存できない失敗と、重複や未登録による拒否の後は、一覧を読み直して表示する。別のリポジトリへ切り替えると、その表示は消す。ダイアログを開いてから登録が終わるまでは、次の登録・解除を受け付けない。その間に別のリポジトリへ切り替えた場合は、登録後もその選択を保つ。左列には切り替えの下に、選んだリポジトリの管理 root のパス（ホームを `~` とし、深いパスは最後の 2 階層だけを 1 行で示す。完全なパスは切り替えのメニューに出る）と「登録を解除」を置く。中央の列の上端のバーには選んだリポジトリの表示名を、その下に保存先の状態（読み込み中、件数、読み直し中、読み込み失敗と再読み込み）を示す。解除すると一覧の先頭のリポジトリを開く。起動時は下の「起動時の復元」に従う。


### 起動時の復元

起動すると、前回の終了時（`session.json` に最後に書いた時点）のウィンドウの大きさと位置、リポジトリ、状態・種類・label の絞り込み、階層とフラットの切り替えから始める。最大化していたウィンドウは最大化して開き（元に戻すと最大化する前の大きさと位置になる）、全画面にしていたウィンドウは全画面にせず、全画面にする前の大きさと位置で開く。ウィンドウは前回と同じディスプレイ（OS がディスプレイを示さなかった場合は主ディスプレイ）に開く。そのディスプレイが今つながっていなければ主ディスプレイの中央に、タイトルバーがそのディスプレイのメニューバーと Dock を除いた範囲に掴める幅（80、ウィンドウがそれより狭ければその幅）で載らない位置ならそのディスプレイの中央に、保存した大きさで開く。大きさは、タイトルバーを含めてディスプレイのメニューバーと Dock を除いた範囲より大きくせず、最小サイズより小さくしない。最後のリポジトリが登録から外れていれば一覧の先頭のリポジトリを開き、ほかの値は復元する。登録の一覧を読めなかった場合は、読み直せたときに最後のリポジトリを開く。検索欄は空、詳細は閉じた状態で始まり、「衝突」は選択済みから始まる（「衝突」の選択肢は記録に衝突がある間だけ出すため、隠れた選択が後の衝突を隠さないよう、リポジトリを切り替えたときと同じ扱いにする）。`session.json` を使えないときは、既定の大きさで画面の中央に開き、一覧の先頭のリポジトリと絞り込みの初期値、階層で始める。`axon gui` のリンクで起動したときは、復元したリポジトリを読み始めた後に、リンクのリポジトリへ切り替わる（下の「CLI から開く」）。

### ウィンドウの幅と列

ウィンドウの幅で、横に並べる列の数を決める。

| 幅 | 列 |
| --- | --- |
| 980 以上 | 左列（リポジトリと絞り込み）・一覧・詳細 |
| 700 以上 980 未満 | 一覧・詳細 |
| 700 未満 | 一覧か詳細のどちらか |

ウィンドウを広げるときは表の幅で列が増え、狭めるときは境界より 20 下回るまで列を保つ。境界の近くで止めた幅で、列が出たり消えたりを繰り返さないようにするためである。

どの幅でも同じ規則で操作を置く。

- 各列の上端に同じ高さのバーを置き、その列の名前と、その列への操作を載せる。左列は「リポジトリ」、一覧はリポジトリの表示名、詳細は Issue / Group・label・ID を示す。
- 詳細のバーの左上のボタンは、どの幅でも一つ戻る。詳細の中のリンクで別の詳細へ移った後は「戻る」でリンク元の詳細へ戻る。最初の詳細では、二列以上で「閉じる」として何も選んでいない状態へ、一列で「一覧」として一覧へ戻る。再読み込みで消えた Entity は戻る途中で飛ばす。一覧から行を選び直すと、戻る先は空になる。
- 左列を出さない幅では、一覧のバーの左上のメニューのボタン（三本線）で、左列と同じ内容をウィンドウの左に重ねたパネルとして開く。パネルのバーの同じ位置の「閉じる」、パネルの外のクリック、Escape で閉じ、リポジトリを切り替えたときも閉じる。絞り込みを変えても閉じない。絞り込みが初期値と異なる間は、メニューのボタンに点を付けて、一覧に出ない Entity があることを示す。開いている間はフォーカスを一覧から外し、矢印キーが裏の一覧を動かさないようにする。

一列の幅では、行をクリックするか、一覧にフォーカスがある間に Enter を押すと、一覧の代わりに詳細を表示する。矢印キーでの選択の移動は一覧を表示したまま行う。詳細から一覧に戻ると、選択を保ってその行を表示し、一覧にフォーカスを移す。

行き来の向きが変わるときだけ動きを付け、選択や中身の更新では付けない。詳細へ進むとき（一覧から開く、リンクで移る）は、入ってくる詳細を右から 24px ずらしながら 0.18 秒で浮かび上がらせ、戻るときは左から同じように入れる。一列の一覧と詳細の切り替えも、二列以上の詳細欄の中の切り替えも同じ動きにする。二列以上で一覧から行を選ぶときと、矢印キーで選択を移すときは動かさない。パネルは左から 0.22 秒で入り、同じ緩急でウィンドウ全体を暗くしていく。出るときは 0.16 秒で、暗さも同時に戻す。列の数の切り替えには動きを付けない。OS の「視差効果を減らす」が有効な間は、これらの動きを省いて最後の状態を表示する。

ウィンドウの最小サイズは 380×460 で、どの幅でも一覧・詳細・パネルの操作要素がウィンドウに収まる。

### 共通一覧と詳細

左列（またはパネル）のリポジトリの下に絞り込みを置く。状態（未判断・未着手・着手中・完了・取りやめ・衝突）、種類（Issue・Group）、label をチェックボックスで選び、中央の検索欄の文字列と組み合わせる。同じ項目の中の選択は OR、項目どうしと検索は AND で、ある項目の選択をすべて外すと一致はゼロ件になる。状態は実効値で判定し、保存値が未着手の Group は、直下の子の実効値が着手中か完了なら着手中になる（[Group の実効 lifecycle](lifecycle.md#group-の実効-lifecycle)）。衝突中の Entity は lifecycle を持たないため「衝突」として扱い、種類・label・検索は最初の head の値で判定する。検索はタイトル・本文・ID に対する大文字小文字を区別する部分一致である。タイトルと本文だけを見る `axon list --search` と違って ID も対象にし、CLI の出力などで見た ID から、完全 ID でも CLI が受け付ける suffix でもその一部でも Entity を探せる。ただし、絞り込みで外れた状態の Entity は ID で検索しても一覧に出ない。「衝突」の選択肢は、最後に読み込んだそのリポジトリの記録に衝突中の Entity がある間だけ出す。出していない間は「衝突」を選択済みとして扱い、外したまま隠れた選択が後で起きた衝突を一覧から隠すことはない。リポジトリを切り替えると、読み込みが終わるまで選択肢を出さず、前のリポジトリの衝突の有無を引き継がない。このため、外していた「衝突」は切り替えで選択済みに戻る。同じリポジトリの読み直し中と読み込み失敗の間は、前回の読み込みでの有無に従う。初期値は未判断・未着手・着手中・衝突、両方の種類、すべての label で、「絞り込みを初期値に戻す」で検索とともに戻る。起動時は前回の絞り込みを復元する（上の「起動時の復元」）。絞り込みはリポジトリを切り替えても保つ。

中央の一覧は「階層」と「フラット」を切り替えられ、初期表示は階層とし、起動時は前回の表示形式を復元する。階層では包含に沿って字下げし（字下げは 8 段までで、それより深い Entity も 8 段で示す）、兄弟は作成順に並べる。一致した Entity の祖先が一致しない場合は「参考表示」と明記して薄く表示し、件数は「N 件が一致 / 参考表示の親 M 件」のように一致件数から除く。親が記録にない Entity と包含の循環の最初の Entity は最上位に置き、各 Entity は一度だけ現れる。フラットは一致した Entity だけを作成順に並べる。階層では包含の段ごとに細い罫線を引き、同じ Group の行をひとまとまりに見せる。各行は状態の記号とタイトル、ID・Issue / Group・状態・状況（着手可・前提待ち・完了確認待ちなど）・label を示す。ID は 2 行目の先頭に置き、狭い一覧で切り詰められても見えるようにする。その分、ID の長さと一覧の幅によっては 2 行目の後ろにある「構造の違反」や「参考表示」の注記が切り詰められて見えなくなる。参考表示の行は薄く表示するため、注記が切れても区別できる。タイトルの行と種類・状態などの行は折り返さず切り詰め、すべての行を同じ高さにする。一覧は表示範囲の行だけを組み立てるため、描画の時間は記録の件数に比例しない。行をクリックすると詳細を開き、右クリックのメニューで「ID をコピー」「タイトルをコピー」「ID とタイトルをコピー」を選ぶと、詳細を開かずにクリップボードへコピーする。「ID とタイトル」は CLI の一覧と同じ並びで `ID タイトル`（例: `axon-abcd1234 案内を送る`）の形にする。衝突中の Entity のタイトルは、一覧の表示と同じく最初の head の値である。一覧は Tab でもフォーカスでき、フォーカスがある間は上下の矢印キーで選択を移し、選んだ行が見える位置までスクロールする。リポジトリに Entity がない場合と、絞り込みに一致しない場合は別の文言で示し、後者には初期値に戻すボタンを出す。別のリポジトリへ切り替えた後の読み込み中と、読み込み失敗の間は前回の一覧を表示しない。

右列は選んだ Entity の詳細で、バーに戻るボタンと Issue / Group・label・ID、ID をクリップボードにコピーするボタンを置き（ID が幅に収まらず切り詰められても、ボタンは完全な ID をコピーする）、その下に上から、タイトル、状態（未判断・未着手・着手中・完了を順に並べた線路の上の現在地として示し、取りやめと衝突は線路の外に示す）、状況（Group の実効値が保存値と異なる場合は保存値も示す）、所属（祖先の列）、衝突と構造の違反（あれば）、前提待ちの理由（着手・完了の前提、止まっている Group の理由）、本文、保存された再浮上条件、子と子孫の件数、依存先、この仕事に依存している Entity、Note、履歴を示す。祖先・子・依存先・依存元・前提待ちの理由・違反に出る Entity はクリックで詳細へ移れ、記録にない ID はそのまま示す。これらの Entity も一覧の行と同じ右クリックのメニューで ID・タイトル・`ID タイトル` をコピーでき、記録にない ID はタイトルがないため「ID をコピー」だけを出す。選んだ Entity が絞り込みに一致しなくなっても詳細を閉じず、一致しないことと、一致しない項目（選んでいない状態・種類・label、タイトル・本文・ID にない検索語）を示す。詳細を閉じると、右列は空の表示に戻る。一覧に一致する行がある間だけ、一覧から選ぶよう促す一文を出す。詳細には操作の可否や操作の案内を出さない。

本文と Note は、記録に形式の印がないため内容から推定せず、常に Markdown（GFM。見出し・強調・箇条書き・引用・コード・テーブルなど）として描画する。段落の中の単独の改行は、GitHub のコメント欄と同じく改行として表示し、CLI やエージェントが改行で区切って書いた本文を書いたとおりに読めるようにする。HTML のタグのうち、アプリが描画せずに消してしまうもの（`<id>` や `<Entity ID>` のような引数の書き方など、文字の装飾や構造に使う HTML のタグ以外）は、書かれたとおりの文字として示す。リンクは、scheme が http・https のものだけを左クリックか中クリックで既定のブラウザで開き、ほかの scheme（`file:` など）と右クリック（Control キーを押したクリックを含む）では開かない。画像は読み込まない。Markdown の画像と HTML の `<img>` は、その位置に代替テキストを示す（代替テキストがなければ「（画像）」）。記録を開いただけで外部へ通信したり、ローカルのものを開いたりしないようにするためである。タイトルと再浮上条件は Markdown として解釈せず、タイトルはそのまま、再浮上条件はコードブロックとして書かれたとおりに示す。

タイトル・本文・Note・再浮上条件の文字はドラッグで選択でき、編集メニューの「コピー」か ⌘C で、選択した文字を表示どおりにクリップボードへコピーする。Markdown の記号・装飾・リンク先の URL と、箇条書きの記号や番号は含まず、前後の空白は除く。

一覧と詳細は保存先を一度読んだ値から導き、表示の状況・前提・履歴は CLI と同じ導出に従う。再浮上条件のコマンドは実行せず、すべて満たしているものとして表示する。リポジトリを切り替えると選択を外し、前のリポジトリの読み込み結果を表示しない。

CLI などでの外部の変更は、一覧の「再読み込み」と、ウィンドウが前面に戻ったとき（アクティブになったとき）に選択中のリポジトリを読み直して反映する。ファイルの監視はしない。前面に戻ったときは選択中のリポジトリを読み直し、登録の一覧を読めなかった場合は状態の欄の「再読み込み」と同じく一覧から読み直す。ウィンドウが背面に回ったときは読まない。すでに読み込みや登録・解除が進んでいる間、またはフォルダを選ぶダイアログを開いている間に前面に戻った場合は、その結果を表示し、読み込みを重ねない。その読み込みが始まった後の変更は、次に前面に戻ったときか「再読み込み」で反映する。同じリポジトリの読み直しでは、結果が出るまで前回の一覧と詳細を表示し続け、状態に「読み直し中」と示す。絞り込み・階層とフラット・選択・一覧と詳細のスクロール位置は保ち、選択した Entity が残っていれば新しい記録の詳細に置き換える。読み直しに失敗した場合は前回の一覧を出さず、選択を外して失敗を示す。

### 配色

状態は、一覧の記号・絞り込みの選択肢・詳細の線路とリンクのどこでも同じ状態ごとの色で示す（未判断は紫、未着手は青灰、着手中は琥珀、完了は緑、取りやめは灰、衝突は赤）。それ以外は無彩色に近い灰青と墨で塗り、色の付いた要素が状態・リンクと選択・注意（前提待ち・絞り込みから外れた選択）・エラーのどれかを示すようにする。配色はシステムの外観（ライト・ダーク）に追従して、入力欄・ボタン・チェックボックスが使う GPUI Component のテーマにも書き込む。

### キーボードとメニュー

Tab と Shift-Tab はフォーカスを移す。一覧も Tab でフォーカスでき、フォーカスがある間は上下の矢印キーで選択を移し、一列の幅では Enter で詳細を開く。Escape はパネルが開いていれば閉じ、そうでなければ詳細のバーの左上のボタンと同じく一つ戻る。ウィンドウを閉じるとアプリを終了する。macOS のメニューバーには終了と、編集（取り消す・やり直す・カット・コピー・ペースト・すべてを選択）を置き、編集は検索欄で使う。「コピー」と ⌘C は検索欄以外でも使え、次の順でコピーするものを決める。検索欄にフォーカスがある間は検索欄で選択した文字。そうでなく、ウィンドウの中（詳細）に選択した文字があればその文字（一覧にフォーカスがあっても選択した文字を優先する）。どちらでもなく一覧にフォーカスがあれば、選んでいる行の ID（詳細のバーのコピーボタンと同じ中身）。

## CLI から開く

`axon gui`（[CLI と表示の契約](cli.md#デスクトップアプリで開く)）は、管理 root を `me.gin0606.axon://open?root=<percent-encode した絶対パス>` のリンクで渡す。scheme はアプリの bundle identifier と同じ文字列である。macOS は `.app` が起動していればそこへリンクを渡し、していなければ起動してから渡す。`.app` にまとめずに起動した実行ファイルは scheme を登録しないため、リンクを受けられない。それが同じデータの保存場所で単一起動 lock を持っていると、リンクで起動した `.app` は説明のウィンドウだけを出し、リンクは開かれない。

- アプリはリンクの管理 root を選択し、ウィンドウを前面に出す。リンクで起動したときも、前回のリポジトリではなくリンクの管理 root を開く。登録済みかどうかはリンクのパスと登録の一覧を文字列で照合し、登録済みなら確かめずに選択する（すでに登録した旨は示さない）。未登録なら、ディスクに触れる前にパスを示して登録してよいかを確かめるダイアログを出す。Escape でキャンセルでき、Return では登録しない。「登録して開く」を選んだときだけ、そのパスが今もそれ自身に解決される（symlink を含まない）ことを確かめてから、「＋ リポジトリを登録」と同じ規則で登録する。別の場所に解決されれば登録しない。`axon gui` は解決済みのパスを送る。キャンセルすればそのフォルダの登録も読み込みもしない（表示中のリポジトリは前面に戻ったときと同じく読み直す）。登録する管理 root を利用者が自分の見たパスで選ぶ理由は [設計判断](../design/decisions.md#リンクで開く管理-root-を利用者が確かめる理由) にある。ダイアログと理由の表示では、パスのバックスラッシュ、制御文字、行・段落の区切り、見えない書式文字（ゼロ幅文字や表示順を入れ替える文字）をエスケープする。登録できない場合は理由を中央の列の上部に示し、狭い幅で詳細を表示していれば一覧に戻して見えるようにする。
- 起動直後で登録の一覧を読み込み中の間、フォルダを選ぶダイアログや登録の確認を開いている間、登録・解除の途中は、それが終わってから開く。ダイアログはウィンドウの前に残す。その間に終わった登録・解除の結果の表示は消さず、リンクを開けなかった理由はその後に足す。リンクが届いた後に利用者が別のリポジトリへ切り替えた場合は、リンクの管理 root を登録してもその選択を保つ。待っている間に届いたリンクは最後のものだけを開く。
- 登録の一覧を読めない状態でリンクを処理するときは、一覧を一度読み直す。読めれば開き、読めなければ登録せずにその旨を示す。

## 既知の制約

- ウィンドウを動かすか大きさを変えてから 0.5 秒以内に最大化するか全画面にすると、その直前の位置と大きさは次の起動に残らず、その前に止まっていた位置と大きさで復元する。最大化と全画面に移る途中の大きさを、最大化する前の大きさとして残さないためである。
- macOS では、ディスプレイの見える範囲いっぱいの大きさのウィンドウは、最大化していなくても最大化として残る（GPUI が大きさで最大化を判定するため）。
- 本文と Note のリンクは、表示された文字とリンク先の URL が異なっても、開く前に URL を示さない。
- `<img>` か描画されないタグだけの行で始まる HTML ブロックは段落として描画するため、ブロックの続く行も Markdown として解釈する。ほかのタグで始まる HTML ブロックの中と、`$` で囲まれた部分の中のタグは、描画されないものでも書かれたとおりには示さない。
- HTML ブロックの中の `<svg>`・`<math>`・`<select>` の中や、HTML の書き方の誤りの後では、`<img>` の代替テキストを示さないことや、描画されない `<img>` の代替テキストを示すことがある。この場合も画像は読み込まない。
- 本文と Note は、描画の前の書き換えのために UI thread で解析するため、数百 KB の本文や Note を初めて開くときは画面が一瞬止まることがある。
- 詳細の文字を選択した後、外部の変更の読み直しなどでその文字が詳細から消えると、ウィンドウをクリックするまで Escape などのキー操作が効かない。戻る操作で消える場合は詳細の列にフォーカスを移す。
- 検索は表示した文字ではなく記録の本文（Markdown の記号やリンク先の URL を含む）に対して行うため、装飾をまたぐ語は表示どおりに入力しても一致しないことがある。
- 登録は管理 root のパスで識別するため、リポジトリを移動・改名すると元の登録は見つからない登録先のエラーになる。移動先を改めて登録し、元の登録を解除する。
