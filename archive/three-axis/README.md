# 三軸実装の過去資料

単一lifecycleへの置換前の、未コンパイルのRust moduleとCLIテストを保存しています。現在のCargo target・CI・実装契約には含めません。旧Revision・claim・schema migrationなどを新実装へ流用しないでください。

現在の正本は [lifecycle spec](../../spec/lifecycle_proposal.md)、実装は [src/lib.rs](../../src/lib.rs) と [src/main.rs](../../src/main.rs)、検証は [検証方針](../../docs/development/verification.md) を参照してください。
