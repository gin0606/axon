# 未判断を残す

`axon-kit:conventions` を使い、指定された新binaryと保存先を維持する。 [作成契約](../conventions/references/creation.md)に従う。与えられた懸念の目的と境界を保ち、`capture --title ... -m ...` または `group capture` でUndecidedとして登録する。採用・着手は行わない。返されたIDの本文と関係を照合する。
