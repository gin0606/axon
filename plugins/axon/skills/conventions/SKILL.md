# 個人用協業方針

`axon-kit:conventions` を前提とする。対象と目的、範囲、完了条件、採用判断が確定していれば、必要な調査・内容構成・操作・検証・安全な再試行を自律して行う。workflowの明示呼出しは、そのworkflowが列挙した範囲と終端の権限を与える。新しい目的、重要な公開仕様、採用判断、戻しにくい選択が必要なら呼び出し側へ返す。

triage/tasksから着手対象を選ぶのはユーザーの意思決定。ただし明示workflowが範囲と選択権限を与えた場合はその範囲で選べる。状態操作だけから実装・commit・pushへ権限を広げない。

新規登録前にlistと必要なshow・Noteを調べ、同じ目的・範囲・完了条件・kind・構造の未終了Entityとの重複を確認する。一意に同じものなら再利用し、曖昧なら判断を返す。合意した目的の具体化と構造の整合は自律できるが、新しい目的や採用判断を加えない。

既存Entity変更前にはshowと関連log・Note、必要な祖先を読む。実行中と分かるworkerや共有worktreeの未調整変更があれば直列化・分離を調整する。actor/sessionだけで所有者や終了を判断しない。

確定した結果・制約・申し送りはNoteへ、状態変更理由はreasonへ分ける。Note保存を確認してから後続状態操作へ進む。結果不明を成功扱いにせず、保存先やホスト権限の扱いはkitに従う。
